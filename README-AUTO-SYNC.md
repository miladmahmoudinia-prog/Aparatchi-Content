# همگام‌سازی خودکار آپاراتچی با API نشر رایگان آپرا

این بسته را در ریشه مخزن عمومی `Aparatchi-Content` آپلود کنید.

## راه‌اندازی یک‌باره

1. در مخزن `Aparatchi-Content` وارد **Settings** شوید.
2. مسیر **Secrets and variables → Actions** را باز کنید.
3. روی **New repository secret** بزنید.
4. نام Secret را دقیقاً `UPERA_REF_ID` قرار دهید.
5. مقدار آن را برابر «شناسه کاربری دسترسی به API» در پنل آپرا قرار دهید.
6. در تب **Actions**، گردش‌کار **Sync Upera Free Catalog** را باز و یک بار **Run workflow** کنید.

`UPERA_TOKEN` فقط برای ناشر ثالث است و برای حساب عادی لازم نیست. در صورت ارائه توکن از طرف آپرا، می‌توان Secret دیگری با همین نام ساخت.

## عملکرد

- هر ساعت عنوان‌ها و قسمت‌های تازه/به‌روزشده بررسی می‌شوند.
- هر اجرا چند صفحه از آرشیو قدیمی را نیز تکمیل می‌کند.
- فقط لینک‌های رایگان با `amount: 0`، فایل‌های MP4 و پخش HLS نگه داشته می‌شوند.
- لینک فروش اشتراکی، صفحه Embed و لینک‌های بدون فایل مستقیم منتشر نمی‌شوند.
- فیلم یا قسمتی که دیگر لینک رایگان معتبر ندارد، در زمان پردازش بعدی حذف می‌شود.
- اپ موبایل بدون ساخت APK تازه، `catalog.json` جدید را دریافت می‌کند.

## نکته درباره شناسه معرف

شناسه در تنظیمات Workflow به‌صورت GitHub Secret نگهداری می‌شود؛ اما چون لینک نهایی درآمد ترافیک شامل `ref` است، این شناسه داخل URL خروجی قابل مشاهده خواهد بود. این رفتار طبیعی لینک معرف است.
