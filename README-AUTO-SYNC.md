# همگام‌سازی خودکار آپاراتچی با API نشر رایگان آپرا

این بسته را در ریشه مخزن عمومی `Aparatchi-Content` آپلود کنید.

## راه‌اندازی یک‌باره

1. در مخزن `Aparatchi-Content` وارد **Settings** شوید.
2. مسیر **Secrets and variables → Actions** را باز کنید.
3. روی **New repository secret** بزنید.
4. نام Secret را دقیقاً `UPERA_REF_ID` قرار دهید.
5. مقدار آن را برابر «شناسه کاربری دسترسی به API» در پنل آپرا قرار دهید.
6. در تب **Actions**، گردش‌کار **Sync Upera Catalog** را باز و یک بار **Run workflow** کنید.

`UPERA_TOKEN` فقط برای ناشر ثالث است و برای حساب عادی لازم نیست. در صورت ارائه توکن از طرف آپرا، می‌توان Secret دیگری با همین نام ساخت.

`TMDB_BEARER_TOKEN` اختیاری است. بدون آن نیز مرحله عوامل ابتدا داده بازیگران و کارگردان را مستقیماً از آپرا می‌گیرد و سپس، در صورت نیاز، از IMDb کمک می‌گیرد.

## عملکرد

- هر ساعت ابتدا عنوان‌های تازه، سپس عوامل و در پایان صف تکمیل آرشیو سریال‌ها بررسی می‌شود.
- تست‌های رگرسیون پیش از هر همگام‌سازی اجرا می‌شوند و در صورت شکست، مرحله دریافت محتوا آغاز نمی‌شود.
- صف آرشیو روی تعداد کمتری سریال و قسمت‌های بیشتری از هر سریال تمرکز می‌کند تا خروجی هر اجرا قابل مشاهده باشد.
- فقط لینک‌های رایگان با `amount: 0` نگه داشته می‌شوند: فایل MP4، پخش HLS و صفحه معتبر ویژه اینترنت همراه در دامنه‌های آپرا/`redl.ink`.
- پاسخ ۴۰۴ لینک وابسته دوباره درخواست نمی‌شود و نتیجه هر عنوان/قسمت در همان اجرا کش می‌شود.
- قسمتی که سه بار واقعاً بدون لینک باشد، مانع انتشار همیشگی کل سریال نمی‌شود؛ پس از ثبت به‌عنوان ناموجود، هفته‌ای یک‌بار دوباره بررسی خواهد شد.
- داده و لینک معتبر قبلی هنگام خطای موقت منبع حذف نمی‌شود.
- اپ موبایل بدون ساخت APK تازه، `catalog.json` جدید را دریافت می‌کند.

برای اجرای دستی از ریشه مخزن، هر دو فرمان زیر به همان پیاده‌سازی نگهداری‌شده اشاره می‌کنند:

```bash
node sync-upera.mjs
# یا
node scripts/sync-upera.mjs
```

## نکته درباره شناسه معرف

شناسه در تنظیمات Workflow به‌صورت GitHub Secret نگهداری می‌شود؛ اما چون لینک نهایی درآمد ترافیک شامل `ref` است، این شناسه داخل URL خروجی قابل مشاهده خواهد بود. این رفتار طبیعی لینک معرف است.
